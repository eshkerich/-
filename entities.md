# Описание предметной области

Платформа доставки еды и аналитики заказов представляет собой специализированную систему для оформления заказов на доставку или самовывоз, управления пользовательскими профилями и сбора статистики по заказам. Системы такого рода применяются в сервисах доставки еды (Додо Пицца, Delivery Club, Яндекс.Еда), внутренних платформах ресторанных сетей и аналитических сервисах.

Работа платформы состоит из следующих этапов:

1. В системе регистрируется пользователь (гость, клиент, оператор или администратор).
2. Пользователю назначается роль, определяющая уровень доступа к функциям платформы.
3. Пользователь заполняет расширенный профиль (отображаемое имя, адрес доставки, контактные данные).
4. Администратор управляет меню: категориями, товарами и их параметрами (размеры, цены).
5. Клиент просматривает меню, ищет блюда и формирует состав заказа.
6. Клиент указывает способ получения (доставка или самовывоз) и подтверждает заказ.
7. Система автоматически рассчитывает итоговую стоимость с учётом доставки и скидок.
8. Оператор/менеджер обрабатывает заказ и изменяет его статусы.
9. Все действия пользователей и критические системные события записываются в журнал действий.

# *Список таблиц для БД с описаниием назначения*

# Сущность "Роль" (Role)

| Поле         | Тип     | Ограничения             | Описание                             |
| ------------ | ------- | ----------------------- | ------------------------------------ |
| role_id      | INT     | Primary Key, Unique     | идентификатор роли                   |
| role_name    | VARCHAR | длина до 50 символов    | название роли (ADMIN, CLIENT и др.)  |
| role_description | VARCHAR | длина до 250 символов | описание полномочий роли             |

# Сущность "Пользователь" (User)

| Поле           | Тип      | Ограничения                | Описание                       |
| -------------- | -------- | -------------------------- | ------------------------------ |
| usr_id         | INT      | Primary Key, Unique        | идентификатор пользователя     |
| usr_login      | VARCHAR  | длина до 50 символов       | имя аккаунта пользователя      |
| usr_email      | VARCHAR  | длина до 100 символов      | адрес электронной почты        |
| usr_password   | VARCHAR  | длина до 255 символов      | хэш пароля пользователя        |
| usr_role_id    | INT      | Foreign Key                | роль пользователя (ссылка на Role) |
| usr_is_active  | BOOL     | default TRUE               | статус активности аккаунта     |
| usr_created_at | DATETIME | -                          | время создания аккаунта        |

# Сущность "Профиль пользователя" (UserProfile)

Описывает расширенную информацию пользователя (связь 1:1 с User)

| Поле            | Тип      | Ограничения              | Описание                                   |
| --------------- | -------- | ------------------------ | ------------------------------------------ |
| prf_usr_id      | INT      | Primary Key, Foreign Key | идентификатор пользователя (ссылка на User)|
| prf_display_name| VARCHAR  | длина до 100 символов    | отображаемое имя                           |
| prf_phone       | VARCHAR  | длина до 20 символов     | контактный телефон                         |
| prf_avatar_url  | VARCHAR  | длина до 255 символов    | ссылка на аватар                           |
| prf_updated_at  | DATETIME | -                        | время последнего обновления профиля        |

# Сущность "Права доступа" (Permission)

| Поле         | Тип     | Ограничения             | Описание                             |
| ------------ | ------- | ----------------------- | ------------------------------------ |
| perm_id      | INT     | Primary Key, Unique     | идентификатор права                  |
| perm_name    | VARCHAR | длина до 100 символов   | название права (CREATE_ORDER и др.)  |
| perm_description | VARCHAR | длина до 250 символов | описание права доступа               |

# Сущность "Роль-Права" (RolePermission)

Разрешает связь M:N между Role и Permission

| Поле         | Тип     | Ограничения             | Описание                             |
| ------------ | ------- | ----------------------- | ------------------------------------ |
| rp_id        | INT     | Primary Key, Unique     | идентификатор записи                 |
| rp_role_id   | INT     | Foreign Key             | роль (ссылка на Role)                |
| rp_perm_id   | INT     | Foreign Key             | право (ссылка на Permission)         |

| Поле            | Тип      | Ограничения                | Описание                                           |
