# *Список таблиц для БД с описаниием назначения*
| № | Сущность | Назначение |
|---|----------|------------|
| 1 | users | Пользователи системы |
| 2 | roles | Роли |
| 3 | permissions | Права доступа |
| 4 | audit_log | Журнал действий пользователя |
| 5 | addresses | Адреса доставки клиентов |
| 6 | categories | Категории меню |
| 7 | products | Товары (пиццы, напитки) |
| 8 | orders | Заказы |
| 9 | order_items | Позиции заказа (кол-во, цена) |
| 10 | payments | Платежи |
| 11 | promocodes | Промокоды |
| 12 | order_status_history | История статусов заказа |
| 13 | deliveries | Доставки |
